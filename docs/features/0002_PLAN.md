# Final Jeopardy Parser Execution & Verification Plan

## Description

Create an execution mechanism to run the existing Final Jeopardy parsing service (`final-jeopardy-parser.service.ts`) against all raw TSV files from Seasons 33-41, produce cleaned JSON output, and verify the correctness of the parsing results through validation checks and metadata inspection.

## Files to Create

- `backend/src/scripts/parse-final-jeopardy.ts` - Standalone script to execute the parser
- `backend/src/scripts/verify-parsed-output.ts` - Script to validate parsed output integrity
- `backend/src/data/parsing/parsing.module.ts` - NestJS module to register the parser service (optional, if using NestJS context)

## Files to Modify

- `backend/package.json` - Add npm script to run the parser execution
- `backend/src/app.module.ts` - Optionally register parsing module if using NestJS DI

## Algorithm

### Phase 1: Execution Script

1. **Initialize Parser Service**
   - Create instance of `FinalJeopardyParserService`
   - Use default constructor (no test directories) to use production paths
   - Service will resolve paths to `backend/data/jeopardy_clue_dataset/raw` and `backend/data/jeopardy_clue_dataset/parsed`

2. **Execute Parsing**
   - Call `parseAllSeasons()` method
   - This will:
     - Read all files from `backend/data/jeopardy_clue_dataset/raw/` matching `season{33-41}.tsv`
     - Filter for `round = 3` (Final Jeopardy)
     - Validate required fields: `category`, `answer`, `question` must be non-empty
     - Deduplicate clues using composite key (category|question|answer)
     - Write output to `backend/data/jeopardy_clue_dataset/parsed/final-jeopardy-clues.json`

3. **Capture Results**
   - Store the `ParsingResult` returned from `parseAllSeasons()`
   - Log the result summary to console
   - Handle any errors thrown during execution

### Phase 2: Output Verification

1. **Read Output File**
   - Load `backend/data/jeopardy_clue_dataset/parsed/final-jeopardy-clues.json`
   - Parse JSON content

2. **Validate Metadata**
   - Check `metadata.totalClues` matches `clues.length`
   - Verify `metadata.totalFilesProcessed` equals 9 (seasons 33-41)
   - Confirm `metadata.validRows` equals `clues.length` (after deduplication)
   - Verify `metadata.duplicatesSkipped` is a non-negative number
   - Check `metadata.processedAt` is a valid ISO timestamp

3. **Validate Data Integrity**
   - Verify all clues have required fields:
     - `seasonNumber`: number between 33-41
     - `category`: non-empty string
     - `answer`: non-empty string
     - `question`: non-empty string
     - `sourceFile`: string matching pattern `season{33-41}.tsv`
   - Verify no duplicate clues exist (check deduplication worked):
     - Create Set of deduplication keys (category|question|answer)
     - Verify Set size equals array length
   - Verify all clues are Final Jeopardy (implicitly true since parser filters for round=3)

4. **Validate Counts**
   - Compare `ParsingResult` counts with output file metadata:
     - `result.validRows` should equal `metadata.totalClues`
     - `result.totalFilesProcessed` should equal `metadata.totalFilesProcessed`
     - `result.duplicatesSkipped` should equal `metadata.duplicatesSkipped`
     - `result.finalJeopardyRowsFound` should be >= `metadata.totalClues` (since duplicates are removed)

5. **Log Verification Results**
   - Report any discrepancies found
   - Display summary statistics
   - Exit with appropriate status code (0 for success, 1 for validation failures)

## Validation Rules

### Required Output File Structure
```typescript
{
  metadata: {
    totalClues: number,
    totalFilesProcessed: number,
    totalRowsRead: number,
    finalJeopardyRowsFound: number,
    validRows: number,
    invalidRows: number,
    duplicatesSkipped: number,
    processedAt: string (ISO timestamp)
  },
  clues: ParsedFinalJeopardyClue[]
}
```

### Validation Checks
1. **File Existence**: Output file must exist at expected path
2. **JSON Validity**: File must contain valid JSON
3. **Metadata Consistency**: All metadata fields must be present and consistent
4. **Data Completeness**: All clues must have required fields
5. **Deduplication**: No duplicate clues (same category, question, answer)
6. **Count Accuracy**: Metadata counts must match actual data counts
7. **Season Range**: All season numbers must be between 33-41
8. **Source Files**: All sourceFile values must match expected pattern

## Error Handling

- **Parser Execution Errors**: Catch and log errors from `parseAllSeasons()`, exit with error code
- **File Read Errors**: Handle cases where output file doesn't exist or is unreadable
- **JSON Parse Errors**: Handle malformed JSON in output file
- **Validation Failures**: Report specific validation failures with details, exit with error code

## Execution Method

### Option A: Standalone Node Script (Recommended)
- Create `backend/src/scripts/parse-final-jeopardy.ts`
- Use Node.js directly: `ts-node src/scripts/parse-final-jeopardy.ts`
- Or compile and run: `npm run build && node dist/scripts/parse-final-jeopardy.js`

### Option B: NestJS Command
- Create a CLI command using NestJS CLI module
- Register parser service in module
- Execute via: `npm run start:cli parse-final-jeopardy`

### Option C: NPM Script
- Add script to `package.json`: `"parse:final-jeopardy": "ts-node src/scripts/parse-final-jeopardy.ts"`
- Execute via: `npm run parse:final-jeopardy`

## Expected Output

### Console Logs
- Parser initialization message
- Processing progress for each season file
- Summary statistics from parser
- Verification results
- Success/failure status

### Output File
- Location: `backend/data/jeopardy_clue_dataset/parsed/final-jeopardy-clues.json`
- Format: JSON with metadata and clues array
- Size: Variable based on number of unique Final Jeopardy clues across seasons 33-41

## Verification Metrics

Track and report:
- Total files processed (should be 9)
- Total rows read from all files
- Final Jeopardy rows found (before validation)
- Valid clues after validation
- Invalid rows rejected
- Duplicates skipped
- Final unique clue count
- Any validation errors or warnings
